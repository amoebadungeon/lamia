# LAMIA Android Application 📱

This subfolder contains the native Android application for **LAMIA (AI Assistive Hands-Free Controller & AAC Platform)**.

For full project documentation, architectural diagrams, and feature overviews, please refer to the [Root README](../../README.md).

## Quick Build Instructions
```bash
./gradlew assembleDebug
```
The output APK is generated at:
`app/build/outputs/apk/debug/app-debug.apk`
